How it works

Four steps. Nothing is removed until you've seen exactly what will happen.

1

Scan & find

Snipe opens instantly from its cache and refreshes in a few seconds, with results streaming in as each source finishes. Pick a category on the left, type in the search box, or combine filters.

  • Badges show how safe each item is to remove.
  • A green ✓ means the file is signed by a trusted publisher.
  • Select an item to see its location, signature and removal methods.
2

Check the plan

Uninstall… shows what will happen first: the removal method, running processes that will be closed, and any warnings about shared components.

  • Silent mode for uninstallers that support it.
  • Optional System Restore point.
  • Administrator rights are requested only when needed.
3

Review the leftovers

After the uninstaller finishes, Snipe searches for what it left behind and scores every finding. High-confidence items are pre-selected; the rest are yours to decide.

  • Folders in Program Files, AppData and ProgramData.
  • Registry keys, COM classes, shortcuts, services, tasks and PATH entries.
  • Windows system locations are never touched.
4

Clean up, safely

Selected leftovers are backed up, then removed. Changed your mind? Open History and click Undo to put back the files, registry data, tasks and services Snipe removed.

  • Files in use are deleted at the next restart.
  • Backups are kept for 30 days.

Spot software you shouldn't trust

Snipe verifies the digital signature of every program, process, service, startup entry and scheduled task, including Windows catalog signatures, and looks for the tricks malware commonly uses. Everything that scores 40 or more appears under Untrusted & suspicious.

0CleanSigned by a trusted publisher, nothing unusual.
1–39LowMinor signals, e.g. an unsigned app in Program Files.
40–69UntrustedUnsigned or self-signed and running from user folders or at startup.
70+SuspiciousTampered signature, fake system names, double extensions, encoded scripts.

Remove a threat in one go

Remove threat… stops the running copies, removes every startup entry, scheduled task and service that launches the file, and moves the file to quarantine, all reviewable and undoable.

Get a second opinion

Scan with Defender asks Microsoft Defender for a verdict on that single file without changing anything. Risk scores are heuristics, not an antivirus verdict.

Built to never break Windows

Deleting things with administrator rights is serious. Snipe is careful by design.

  • Hard deny-listWindows folders, profile roots and critical registry keys are never deleted, whatever the score.
  • Quarantine, not deleteFiles are moved aside and registry data is exported before removal, so Undo can restore them.
  • Least privilegeThe UI runs as you. A separate elevated helper starts only when needed and accepts item IDs, never paths or commands.
  • Your uninstallers stay yoursUninstallers registered by a single user always run without admin rights.
  • Protected items are lockedCritical processes, Windows services and system components are shown but can't be removed.
  • No junction tricksLinks are never followed during deletion, and every path is re-checked after resolving it.
  • Restore pointsCreate a System Restore point before any uninstall with one checkbox.
  • Open sourceEvery line is on GitHub under MIT OR Apache-2.0.

Get started

Install

  1. Download Snipe_<version>_x64-setup.exe (or _x86 for 32-bit Windows) from Releases.
  2. Run it. It installs for your user only and fetches the WebView2 runtime if it's missing.
  3. Open Snipe from the Start menu.

Installers aren't code-signed yet, so Windows SmartScreen may ask you to confirm with More info → Run anyway.

Download latest release

Use

  1. Choose a category in the sidebar, or search.
  2. Select an item to see its details, signature and risk.
  3. Click Uninstall…, check the plan, and review leftovers.
  4. Click Admin session to include Windows features and updates.
  5. Use History → Undo if you need anything back.
  6. Use Export CSV / JSON to save the inventory.

Command-line interface

snipe-cli scan                 # summary per source
snipe-cli list chrome          # items matching "chrome"
snipe-cli threats              # untrusted / suspicious items
snipe-cli plan <id>            # uninstall plan, no changes
snipe-cli leftovers <id>       # dry-run leftover scan
snipe-cli export --format csv --out inventory.csv

Build from source

# Rust (rustup), VS Build Tools (C++), Node.js 20+
git clone https://github.com/arteficent/snipe.git
cd snipe/app
npm ci
npm run tauri dev                      # run with hot reload
npm run tauri build -- --bundles nsis  # installer

Questions

Is Snipe an antivirus?

No. Snipe flags software that lacks a trusted signature or behaves like common malware persistence so you can review it. It can't detect validly signed or well-disguised malware. Use “Scan with Defender” or your antivirus for a verdict.

Does it need administrator rights?

Browsing doesn't. Uninstalling, cleaning leftovers, History and scanning Windows features ask for permission once per session through the normal Windows UAC prompt.

What if it removes something I needed?

Open History and click Undo: quarantined files, registry data, scheduled tasks and services are put back. To roll back an uninstaller itself, use the System Restore point Snipe can create first.

Will it touch Windows itself?

Windows components are shown but locked, and Windows folders and critical registry keys are on a hard deny-list. Windows features and updates are only changed through Microsoft's own DISM tool, and only when you ask.

Does it send any data anywhere?

No. Snipe works entirely offline; signature checks don't use the network.
